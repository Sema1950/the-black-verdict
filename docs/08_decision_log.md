# 08 Decision Log

## File Purpose

This file is the single source of truth for all locked, pending, revised, rejected, and deferred project decisions.

The purpose is to prevent decision drift across the project files.

If another file conflicts with this file, this file takes priority until the affected file is updated.

## Decision Log Rules

1. Every major design, lore, scope, technical, or presentation decision must be recorded here.
2. Do not keep the same decision listed as pending in multiple files after it is locked here.
3. When a decision changes, add a new entry instead of silently rewriting history.
4. Older project files should be updated after this file locks a decision.
5. If a decision is uncertain, mark it as Pending, not Approved.
6. If an item is excluded from v1 but may return later, mark it as Deferred to v2.
7. Lore-sensitive decisions must remain marked as Needs Verification until checked against approved sources.
8. IP-sensitive decisions must clearly separate fan-art use from safer original portfolio use.

## Status Labels

Use these labels consistently:

* Approved
* Pending
* Rejected
* Deferred to v2
* Needs lore verification
* Needs IP-safe treatment
* Revised
* Superseded
