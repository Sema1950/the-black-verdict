# 07 Asset Checklist

## File Purpose

This file defines the approved v1 asset list for the game-ready Inquisitor character.

The goal is to prevent scope creep before blockout, high-poly sculpting, retopology, UVs, baking, texturing, grooming, and final presentation begin.

This file controls:

* Which assets are included in v1
* Which assets are excluded from v1
* Which items are pending decision
* Which assets require modeling, sculpting, UVs, textures, groom, or presentation work
* Which assets must be replaced if new items are added

This file should be updated after each major design decision.

## Current Checklist Status

Current status: revised working asset checklist.

The main character direction is locked around custom human-scale power armor.

Locked direction:

* Character type: human-scale Ordo Malleus Inquisitor
* Philosophy: Puritan in philosophy, severe in method
* Psyker status: non-psyker
* Head presentation: bare head as primary
* Face direction: close Henry Cavill-inspired older veteran, not direct commercial replica
* Age read: mid-to-late 40s
* Armor structure: custom human-scale Inquisitorial power armor
* Cloak: long cloak over armor
* Hood: present, resting behind the head or on the upper back
* Tabard / controlled chains: pending visual exploration
* Primary melee weapon: power sword
* Secondary sidearm: bolt pistol
* Books: not included in v1
* Servo-skull: not included in v1
* Helmet: not included in v1
* Space Marine backpack / power unit silhouette: not allowed
* Presentation pose: standing authority pose
* Primary renderer: Marmoset Toolbag for v1

## Status Labels

Use these labels for every asset:

* Approved: included in v1
* Pending: needs decision before final blockout
* Optional: allowed only if it replaces or strengthens another item
* Excluded: not allowed in v1
* V2: possible future addition, not part of v1
* Needs lore verification: do not finalize until checked
* Needs IP-safe treatment: requires safer original handling before final portfolio use

## V1 Asset Scope Rule

The v1 character must stay within this scope:

1. Main character
2. Custom human-scale power armor set
3. Long cloak
4. Hood integrated with cloak or upper back cloth
5. One primary melee weapon: power sword
6. One secondary sidearm: bolt pistol
7. One scabbard / sheath
8. One holster
9. One rosette / authority object
10. Optional tabard or controlled chain arrangement, pending visual exploration
11. One optional signature relic maximum, pending decision
12. Limited purity seals

Anything beyond this list must replace another asset or move to v2.

Do not add props only because they look cool.

## Main Character Assets

### 1. Head And Face

Status: Approved

Purpose:

Hero asset and main portfolio focus.

Included:

* Mature male head
* Close Henry Cavill-inspired facial structure
* Older and more battle-worn than typical Cavill heroic presentation
* Mid-to-late 40s apparent age
* Natural eyes
* No bionic eye in v1
* Calm, severe, controlled expression
* Visible fatigue and field wear
* Subtle scars or marks that support veteran character

Production tasks:

* Base head sculpt
* Likeness sculpt refinement
* Skin pore and wrinkle detail
* Subtle scar and fatigue detail
* Eye setup
* Skin texture set
* Face close-up render

Avoid:

* Perfect celebrity copy by default
* Young heroic face
* Screaming expression
* Glowing eyes
* Bionic eye in v1
* Extreme scars or gore

Status: Approved

Purpose:

Support mature likeness and character authority.

Included:

* Short-to-medium dark hair

Production tasks:

* Beard transition work
* Hair texture creation

## Scope Gate Checklist

Before moving from blockout to high-poly, confirm:

* Main character silhouette works at thumbnail size.
* Face remains the hero asset.
* Character reads as human, not Space Marine.
* Power armor reads as custom Inquisitorial armor.
* Rear silhouette does not read as Space Marine backpack / power unit.
* Cloak improves the Inquisitor read.
* Hood supports silhouette without hiding the face.
* Pauldrons stay human-scale.
* Tabard or chains help the design rather than clutter it.
* Belt / authority zone is not overloaded.
* Rosette is visible or intentionally revealable.
* Only one primary melee weapon is present.
* Only one secondary sidearm is present.
* Optional relic is either approved or removed.
* Purity seals stay within 3 to 5 clusters.
* No books are included.
* No servo-skull is included.
* No helmet is included.
* No fake text or unverified symbols are present.

If any answer fails, fix the asset list before continuing.
