# 02 Reference Sources

## File Purpose

This file controls all reference gathering for the Inquisitor character project.

The goal is to collect useful visual and lore references without mixing official canon, secondary support, fan interpretation, and pure style inspiration.

This file should prevent reference-board chaos.

Current design direction:

A human-scale, non-psyker, Puritan-in-philosophy Ordo Malleus Inquisitor in custom human-scale power armor, with long cloak, hood, possible tabard or controlled chains, power sword, bolt pistol, limited purity seals, and a close Henry Cavill-inspired older veteran face.

## Main Rule

Every reference must be labeled by source type and purpose.

Do not collect images only because they look cool.

Each reference should answer at least one of these questions:

* Does this support lore accuracy?
* Does this support character role?
* Does this support human-scale power armor?
* Does this support silhouette?
* Does this support cloak, hood, tabard, or chain construction?
* Does this support material realism?
* Does this support 3D production quality?
* Does this support likeness sculpting?
* Does this support final presentation?

## Source Categories

Use these categories for every reference:

### A. Primary Official Lore Reference

Official Games Workshop, Warhammer, Warhammer Community, official codex/rulebook, or official miniature/product source.

Use for:

* Lore decisions
* Ordo logic
* Inquisitor rank and role
* Official visual language
* Allowed design elements
* Official equipment direction

### B. Official Visual Reference

Official model images, sprue images, box art, official painted miniatures, official covers, and official licensed art.

Use for:

* Silhouette
* Costume structure
* Proportions
* Materials
* Props
* Symbol placement
* Color logic

### C. Secondary Lore Support

Lexicanum, official-adjacent summaries, interviews, archived material, and high-quality commentary based on official material.

Use only to cross-check or locate official sources.

Do not treat as final canon.

### D. Fan Interpretation

Fan art, Pinterest, Reddit images, ArtStation fan concepts, kitbashes, cosplay, and non-official renders.

Use only for:

* Mood
* Composition
* Production inspiration
* Quality benchmark

Do not use fan interpretation for lore decisions.

### E. Real-World Production Reference

Real clothing, armor construction, leather goods, ceremonial uniforms, aged metals, wax seals, parchment, skin, hair, grooming, chains, cloak construction, and cloth references.

Use for:

* Material realism
* Construction logic
* Wear and aging
* Patterning
* Drapery
* Texture storytelling

### F. Likeness Reference

Henry Cavill face and body references.

Use for:

* Cranial structure
* Jawline
* Brow
* Nose
* Eyes
* Facial planes
* Beard and grooming
* Body proportions
* Expression control
* Mature heroic presence

Important:

This is for private study or portfolio fan-art direction only. Avoid presenting the final character as an official Henry Cavill asset.

### G. Real-Time 3D Quality Benchmark

Official licensed games, cinematics, and professional real-time character presentations.

Use for:

* Material quality target
* Real-time rendering benchmark
* Grime and wear treatment
* Cloth and leather shading
* Groom and skin expectations
* Armor material treatment
* Final presentation quality

Do not use these as final lore authority unless they are official and directly relevant.

### H. Negative Reference

References collected to define what not to do.

Use for:

* Space Marine drift prevention
* Astartes backpack / power unit avoidance
* Overdecorated chain avoidance
* Fantasy knight drift prevention
* Priest / commissar / tech-priest drift prevention
* AI-image artifact avoidance

## Link Reliability Rule

Do not rely on live shop links as permanent sources.

Games Workshop and Warhammer store pages can change, redirect, or disappear when products are reprinted, renamed, region-locked, or removed from sale.

For every important official source:

* Test the link manually in a browser
* Save the product name exactly
* Save screenshots or images locally for private reference
* Record the access date
* Mark the link as Verified, Redirected, Broken, or Needs Recheck

Default status for all store links until tested:

Needs manual verification.

### I. AI Concept Exploration

AI-generated images created during this project.

Use only for:

- Mood
- Composition
- Broad silhouette ideas
- Visual direction testing
- Presentation inspiration
- Discussion of what to keep, modify, or reject

Do not use for:

- Lore authority
- Final symbol design
- Readable text
- Armor construction
- Cloth attachment logic
- Exact prop design
- Final modeling reference

Rule:

AI concept images must always be labeled as non-canon concept exploration.

They must be checked against:
- Official references
- Project visual design bible
- Real-world material references
- Clean 3D construction logic

## Local Image Archive Rule

The project must not become only a list of links.

Store actual image references locally in the project folder.

Each saved image filename should include:

* Source category prefix: A, B, C, D, E, F, G, or H
* Character or source name
* Short description
* Date collected

Example:

## Negative Reference List

These references can easily pull the project in the wrong direction.

Use with caution or avoid unless there is a specific reason.

### Space Marines

Risk:

Can destroy human-scale Inquisitor identity.

Avoid:

* Astartes proportions
* Chapter iconography
* Oversized pauldrons
* Space Marine backpack silhouette
* Astartes-style power unit
* Barrel torso
* Huge boots
* Tiny head relative to armor

Use only for:

* Negative comparison board
* Understanding what not to do

### Adeptus Mechanicus

Risk:

Can make the character read as a tech-priest or Mechanicus agent.

Avoid:

* Excessive cables
* Robes that dominate the silhouette
* Cog motifs
* Tech-priest face treatment

### Adepta Sororitas / Sisters of Battle

Risk:

Close to Ordo Hereticus visually, but different role and hierarchy.

Avoid:

* Battle Sister armor shapes
* Sororitas chest silhouettes
* Ecclesiarchal over-styling
* Too much shrine-like decoration

### Commissars

Risk:

Similar authority tone, but completely different role.

Avoid:

* Pure officer-coat read
* Commissar cap language
* Guard command styling without Inquisitorial authority

### Fantasy Knights And Executioners

Risk:

Tabard and chains can push the design toward fantasy instead of grimdark sci-fi.

Avoid:

* Medieval knight tabard language
* Executioner chain overload
* Fantasy plate armor
* Spikes and skull piles
* Non-functional armor panels

### Pinterest Inquisitor Boards

Risk:

Often mixed with fan art, cosplay, AI images, and unrelated factions.

Rule:

Pinterest can be used only for mood and shape ideas after official references are already collected.

Do not treat Pinterest as lore.

### AI-Generated Images

Risk:

Often invents fake symbols, fake inscriptions, impossible construction, and lore-breaking details.

## 3D Quality Benchmark References

Source type:

G. Production Quality Reference

Use ArtStation, professional portfolios, official game assets, and studio breakdowns only for:

* Sculpt quality
* Skin detail
* Grooming quality
* Cloth material treatment
* Leather material treatment
* Hard-surface armor edge quality
* Real-time rendering standards
* Turntable and breakdown presentation

Do not use:

* Fan concepts for lore decisions
* Overdesigned armor for costume logic
* Random cool shapes without Inquisition reason

Recommended benchmark categories:

* Photorealistic cinematic game character
* Real-time human head sculpt
* Real-time beard and hair groom
* Human-scale hard-surface armor
* Heavy cloak game character
* Leather and aged metal material breakdown
* Unreal Engine 5 character presentation
* Marmoset Toolbag character presentation
* Darktide-level grime and material realism
