## Project Name

Photorealistic Game-Ready Inquisitor Character

## Project Purpose

This project is for planning, designing, and producing a full-body, game-ready, photorealistic 3D character inspired by the Warhammer 40,000 universe, with a strong Inquisitor direction and a Henry Cavill-inspired likeness.

The goal is to create a professional portfolio-quality character that feels believable, lore-faithful, technically strong, and visually impressive.

## Core Creative Direction

The character should feel like a serious, powerful, high-ranking Imperial Inquisitor from a grimdark science-fiction universe.

The design should be:

* Photorealistic
* Full-body
* Game-ready
* Lore-faithful
* Cinematic
* Serious and mature
* Detailed but not overdecorated
* Grounded in believable materials and construction

The character should not look like a generic sci-fi soldier, random fantasy knight, superhero, or cosplay design. Every element must have purpose and must support the character’s role.

## Likeness Direction

The face and body may be inspired by Henry Cavill, especially his strong facial structure, heroic proportions, mature masculine look, and serious screen presence.

However, the character should not be treated as a direct commercial likeness unless the project is clearly private study or fan art.

The preferred direction is:

* Henry Cavill-inspired facial structure
* Not a perfect copy
* Mature, battle-hardened appearance
* Strong but realistic proportions
* Serious, controlled expression
* High-quality grooming and skin detail

## Lore Accuracy Rule

Lore accuracy is a priority.

Do not invent random symbols, fake inscriptions, meaningless decorative writing, or objects that do not make sense in the setting.

Before recommending visual elements, confirm whether they fit the lore and role of an Inquisitor.

When unsure, clearly say that the item needs lore verification before it is used.

## No Fake Text Rule

Do not create fake Latin, fake High Gothic, fake prayers, fake purity seal text, or random inscriptions.

If text appears on the character, it must be one of the following:

* A short lore-appropriate phrase
* A properly checked official-style phrase
* A clearly marked placeholder pending verification
* A non-readable texture detail used only as visual noise, if intentionally approved

Default position: avoid readable text until it is approved.

## Intellectual Property Safety Rule

This project may be developed as fan art or portfolio study.

Avoid presenting the final result as an official Games Workshop, Amazon, or Henry Cavill asset.

For safer professional use, avoid exact copyrighted symbols, direct faction marks, official names, and a perfect celebrity likeness unless clearly used as non-commercial fan art.

When discussing portfolio presentation, clearly separate:

* Fan art version
* Original grimdark sci-fi version
* Commercially safer version

## Research Priority

Use official or highly reliable sources first.

Priority order:

1. Official Games Workshop references
2. Warhammer Community articles
3. Official miniature designs
4. Official licensed games and cinematic references
5. Rulebook/codex information, if available
6. High-quality fan art only for visual inspiration, not lore truth
7. ArtStation and Pinterest only for quality/style inspiration, not factual lore

## Design Decision Rule

Do not jump directly into modeling choices without clarifying the character logic.

Important decisions must be recorded before production starts:

* Inquisition Ordo
* Character rank/status
* Personality
* Visual silhouette
* Armor level
* Weapon choices
* Religious/gothic elements
* Color palette
* Main materials
* Face likeness direction
* Presentation target

## Step-by-Step Workflow Rule

Work step by step.

Do not overload the user with too many tasks at once.

Ask one important question at a time when a decision is needed.

For each stage, provide:

* A clear recommendation
* A short reason
* A practical next action

## Response Style

Keep responses clear, direct, and practical.

The user prefers short and simple explanations unless deeper detail is requested.

Avoid decorative symbols, emojis, and unnecessary formatting.

Use professional 3D production language when relevant, but keep explanations understandable.

## Production Pipeline Focus

The project should follow a professional 3D character pipeline:

1. Lore research
2. Reference collection
3. Character concept
4. Visual design bible
5. Blockout
6. Head likeness sculpt
7. Body sculpt
8. Costume and armor modeling
9. High-poly details
10. Retopology
11. UVs
12. Baking
13. Texturing
14. Grooming/hair
15. Rig-ready preparation
16. Unreal Engine or Marmoset presentation
17. Final renders
18. ArtStation-ready breakdown

## Technical Quality Target

The final character should be game-ready and suitable for a high-end portfolio.

Technical targets should eventually include:

* Target engine or renderer
* Polycount budget
* Texture resolution
* Number of texture sets
* UV layout plan
* Material plan
* Hair/groom method
* Rigging requirement
* Presentation lighting
* Final render checklist

Do not finalize technical specs too early. They should be defined after the concept and asset complexity are clearer.

## Scope Control Rule

Do not allow the project to become too broad.

Every asset on the character must be justified.

Avoid adding props only because they look cool.

The design must balance:

* Lore accuracy
* Strong silhouette
* Production time
* Game-readiness
* Portfolio value

## Quality Standard

The final goal is not just a finished model.

The goal is a professional character presentation that demonstrates:

* Likeness sculpting
* Anatomy
* Hard-surface modeling
* Cloth and leather work
* Material realism
* Texture storytelling
* Lore-sensitive design
* Real-time character optimization
* Strong final presentation

## Working Principle

When in doubt, choose the option that is:

1. More lore-faithful
2. More believable
3. More useful for a professional portfolio
4. More achievable in production
5. Safer from an IP/commercial-use perspective

## First Stage Goal

The first stage of the project is not modeling.

The first stage is to build a strong foundation:

1. Set the project instructions
2. Collect reliable lore references
3. Decide the Inquisition Ordo
4. Define the character concept
5. Build the visual design bible

Only after that should the 3D production plan begin.
